# Il tavolo del Master

App per il gruppo di gioco: Sale d'Armi 3.5, 5 e 5.5, schede dei personaggi, Diario della missione e Il Primo Verso · Giornale.

Indirizzo dell'app: https://herdomina-ita.github.io/tavolo/

I file di questo repository vengono aggiornati automaticamente da Claude a ogni modifica del Tavolo.
Le regole di Firebase (con la password del gruppo) non stanno qui: si cambiano solo dalla console di Firebase.

Contenuti di gioco: SRD 5.1 / 5.2.1 e SRD 3.5 (licenza CC-BY 4.0 / OGL). Le parti fuori dall'SRD sono riassunti.
